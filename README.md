# 📊 Data Jobs Market & Salary Analytics Suite (Microsoft Excel)

An end-to-end Business Intelligence and Data Analytics portfolio project analyzing **32,600+ global data job postings** across roles, countries, employment types, hiring platforms, and technical skills.

This repository features **two complementary Excel workbooks** built on the same dataset, demonstrating two distinct BI architectures:
1. **Part 1 (`Project_Analysis.xlsx`) — Power Query & Power Pivot (DAX):** Relational data modeling (`1:*`) evaluating skill demand, skill likelihood probabilities, and skill-to-salary ROI.
2. **Part 2 (`Data_Science_Salary_Dashboard.xlsx`) — Dynamic Array Formula Engine:** Formula-driven interactive dashboard (`XLOOKUP`, `UNIQUE`, `SORT`, `COUNTIFS`, Data Validation dropdowns, and dynamic chart highlighting) benchmarking salaries by role, country, schedule type, and job portal.
